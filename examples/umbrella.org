*** Pattern applications                                         :nodeclare:
Two step-3 pattern applications, kept deliberately small.

*Function pattern* (=pattern:IDO-pattern-function=) applied to the
canopy of Ursula's umbrella: bearer *bound* (the canopy already
existed), activity kind =umb:rain-shielding= *minted*, function and
realizing-activity individuals *minted*.  Constants =lis:Capability=,
=lis:Function=, =lis:hasCapability=, =lis:hasFunction=,
=lis:realizedIn= and =lis:hasActiveParticipant= were *not* already
present in this file and were borrowed for this application;
=lis:Activity= and =lis:hasParticipant= already were.

*Participation pattern* (=pattern:IDO-pattern-participation=) applied
to the assembly of Ursula's umbrella: both participants *bound* (handle
and shaft already existed), activity kind =umb:umbrella-assembly=
*minted*, activity individual *minted*, plus one repeat leg for the
canopy as a second passive participant -- the sanctioned route to more
than two participants.

Neither application surfaced a latent inconsistency.  The
under-constraint they *do* surface is that nothing forces the canopy
that bears the shielding function to be the same canopy that is
assembled into the umbrella; that identity is carried only by using
the same individual, exactly as with the shaft-length exercise.

*** Units of measure                                             :nodeclare:
In an IDO-compliant ontology a unit of measure is an *individual* -- an
instance of =lis:UnitOfMeasure= (or its subclass =lis:Scale=) -- not a
class.  IDO's =lis:datumUOM= relates a =lis:ScalarQuantityDatum= to a
unit *individual*, so the units must be declared here in the Individuals
section, each typed with =Types :: lis:UnitOfMeasure=.

The units are borrowed from QUDT and cited with =rdfs:isDefinedBy ::
unit:=.  Note that the QUDT vocabularies are *not* imported with
=owl:imports=: QUDT is not OWL DL, so importing it as-is would take the
umbrella ontology out of the DL profile.  We therefore reuse the QUDT
identifiers (and a =qudt:symbol= annotation) while asserting the IDO
typing locally.

 - qudt:symbol :: m
 - skos:definition :: "The SI base unit of length."@en
